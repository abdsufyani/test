# رنّة — نظام تنبيه الطلبات

العميل يمسح QR، تفتح له صفحة برقم طلبه، ويرن جواله لما الكاشير يضغط «جاهز». ما يحتاج تطبيق.

## التشغيل

```bash
cd order-ping
npm install
npm run vapid   # مرة وحدة: يولّد مفاتيح Web Push في .env
npm start       # http://localhost:3000
```

- لوحة الكاشير: `/cashier.html` (الـ PIN في `.env` → `CASHIER_PIN`، الافتراضي 1234)
- صفحة العميل: `/o/<id>` (تطلع من QR)

## طريقة الاستخدام
1. الكاشير يكتب رقم الطلب ← «طلب جديد» ← يطلع QR.
2. العميل يمسح الكود ← «نبّهني لما يجهز» ← يقفل جواله.
3. الكاشير يضغط «جاهز» ← يوصل للعميل إشعار حتى لو جواله مقفل.
4. اللوحة تتابع الحالات: **انرسل ← وصل ← شافه ← جاي**.
5. «تم التسليم» يقفل الطلب.

## النشر (مهم)
Web Push **لازم HTTPS**. على localhost يشتغل بدونه، لكن الجوالات تحتاج دومين عليه HTTPS.
- ارفعه على Render أو Railway أو أي VPS عليه Node 18 أو أحدث.
- حط `BASE_URL=https://دومينك` في `.env` عشان روابط QR تطلع صح.
- ملف `.env` ومفاتيح VAPID لا ترفعها على GitHub (موجودة في `.gitignore`).

## حدود معروفة
| الجهاز | الوضع |
|---|---|
| أندرويد (Chrome) | يرن مباشرة بعد ما العميل يسمح بالإشعارات |
| آيفون (iOS 16.4 أو أحدث) | لازم العميل يضيف الصفحة للشاشة الرئيسية أول، والصفحة تشرح له الخطوات |
| أي جهاز والصفحة مفتوحة | ينبه بصوت واهتزاز (إذا الجهاز يدعم الاهتزاز) عن طريق WebSocket |

## تطويرات لاحقة
- بديل للآيفون: رسالة واتساب أو SMS، أو App Clip.
- ربط مع نظام الكاشير (POS) عشان «جاهز» يصير تلقائي.
- قاعدة بيانات (SQLite أو Postgres) بدل `data.json`، ودعم أكثر من فرع.
