## أ) التدريب على Colab (من جهازك)

1. فك ضغط ملف `waste_pi.zip`.
2. ادخل **roboflow.com** وسوّ حساب مجاني.
3. من **Settings ← API Keys** انسخ المفتاح (Private API Key).
4. ادخل **colab.research.google.com** ← **File ← Upload notebook** ← اختر `train_colab.ipynb`.
5. من **Runtime ← Change runtime type** اختر **T4 GPU** ← **Save**.
6. (اختياري) حط مفتاح Roboflow في **Colab Secrets** (أيقونة المفتاح يسار) باسم `ROBOFLOW_API_KEY` ← فعّل **Notebook access**. لو ما حطيته، الخلية 3 بتطلبه منك.
7. شغّل **الخلية 1** (زر التشغيل ▶) ← وافق على ربط Google Drive.
8. شغّل **الخلية 2** (تثبيت المكتبات).
9. شغّل **الخلية 3** (التنزيل) ← انتظر لين يخلص. الداتا تنحفظ في Drive، فما تنزل مرة ثانية.
   - لو فشل تنزيل النفايات أو الحفر، الخلية **توقف** (إلزامية).
   - لو فشل تنزيل السيارات المهجورة، تكمل بفئتين وتنبهك.
10. شغّل **الخلية 4** ثم **الخلية 5** (الدمج) ← راجع جدول التحويل: كل فئة لازم تكون رايحة لمكانها الصح.
    لو طلع خطأ "ما لقيت فئة"، الرسالة تقولك الأسماء الموجودة: أضف الاسم الصحيح في `MAPPING` داخل `merge_datasets.py` وأعد الخلية 4 و5.
11. شغّل **الخلية 6** (التدريب) ← خلّ الصفحة مفتوحة. ممكن ياخذ ساعات.
    - لو انقطعت الجلسة: أعد الخلايا من 1 إلى 6، ويكمل من حيث وقف.
    - لو أعدت الخلية بعد ما خلص التدريب، تتخطاه وما تبدأ من جديد.
12. شغّل **الخلايا 7 و8** ← جدول النتائج لكل فئة، ومنحنيات التدريب، و Confusion Matrix.
13. شغّل **الخلايا 9 و10** ← تحليل الأخطاء، و6 صور نجاح و6 صور أخطاء.
14. (اختياري) **الخلية 11** ← جرّب على صورك الخاصة.
15. شغّل **الخلية 12** ← ينزل لك ملف `best_ncnn_model.zip`.

كل النتائج تنحفظ في Drive داخل `waste_project/deliverables`، وتشمل:
- `results_table.csv`
- `best.pt` و `best_ncnn_model.zip`
- الصور والمنحنيات
- `merge_stats.json`
- `per_image_errors.csv`

## ب) تجهيز السيرفر (على اللابتوب)

1. اللابتوب والرازبيري لازم يكونون على **نفس شبكة الواي فاي**.
2. اعرف IP اللابتوب:
   - **ماك:** إعدادات النظام ← Wi-Fi ← Details ← IP Address
   - **ويندوز:** افتح CMD واكتب `ipconfig` ← IPv4 Address
3. افتح Terminal داخل مجلد `waste_pi` واكتب (بدّل الـ IP بحقك):

```bash
pip install flask cryptography
python server.py --init
python gen_cert.py 192.168.1.20
```

4. بيطلع لك 3 ملفات:
   - `secret.key` ← **انسخه للرازبيري**
   - `cert.pem` ← **انسخه للرازبيري**
   - `key.pem` ← **يبقى على اللابتوب، لا تنسخه**
5. شغّل السيرفر:

```bash
python server.py
```

6. افتح في المتصفح `https://192.168.1.20:8443` (بالـ IP حقك). المتصفح بيعطيك تحذير لأن الشهادة ذاتية، اضغط **متابعة**. بتطلع لك صفحة المخالفات وتتحدث كل 5 ثواني.

## ج) تجهيز الرازبيري

1. نزّل **Raspberry Pi Imager** على كمبيوترك.
2. اختر: **Raspberry Pi 5** ← **Raspberry Pi OS (64-bit)** ← كرت الذاكرة.
3. في الإعدادات حط: اسم مستخدم وكلمة سر، وشبكة الواي فاي ← اضغط **Write**.
4. **الكاميرا:** افصل الكهرباء ← ارفع قفل منفذ الكاميرا في اللوحة ← دخّل الكيبل ← سكّر القفل ← ركّب الطرف الثاني في الكاميرا.
5. حط الكرت في الرازبيري ← وصّل شاشة وكيبورد وماوس ← وصّل الشاحن.
6. انسخ على فلاش وحطهم في مجلد `waste_pi` بالرازبيري:
   - ملفات المشروع
   - `best_ncnn_model.zip`
   - `secret.key` و `cert.pem` من اللابتوب
7. افتح **Terminal** واكتب:

```bash
cd ~/waste_pi
bash pi_setup.sh
```

8. انتظر لين يخلص ← لازم يطلع **اسم الكاميرا** في الآخر. لو ما طلع، الكيبل مركّب غلط.

## د) التشغيل

1. فعّل البيئة:

```bash
source ~/waste_env/bin/activate
cd ~/waste_pi
unzip best_ncnn_model.zip
```

2. **تجربة سريعة بدون سيرفر** (5 لقطات):

```bash
python pi_detect.py --model best_ncnn_model --frames 5
```

3. **تشغيل مع الإرسال للسيرفر** (بالـ IP حق اللابتوب):

```bash
python pi_detect.py --model best_ncnn_model --server https://192.168.1.20:8443
```

4. للإيقاف اضغط **Ctrl + C** ← يطلع لك الملخص.
5. لو انقطع الواي فاي، اللقطات تنحفظ في `detections/pending` وتنرسل تلقائياً لما يرجع الاتصال.

## هـ) التجارب للرسالة (المقارنة)

شغّل الثلاث تجارب بنفس المكان ونفس عدد اللقطات (مثلاً 100):

```bash
# 1) الطريقة التقليدية: يرسل كل لقطة
python pi_detect.py --model best_ncnn_model --server https://192.168.1.20:8443 --mode fixed --frames 100

# 2) طريقتنا: يرسل المخالفات بس
python pi_detect.py --model best_ncnn_model --server https://192.168.1.20:8443 --mode opportunistic --frames 100

# 3) الجهاز بدون تحليل (لقياس الاستهلاك الأساسي): اتركه 3 دقايق وشغّل
vcgencmd pmic_read_adc
```

كل تجربة تطلع ملف `summary_*.json` في مجلد `detections`، وفيه:
- **البيانات المرسلة** ونسبة التقليل
- **زمن التحليل** و**زمن الإرسال**
- **الطاقة:** متوسط الواط، والجول الكلي، والجول لكل لقطة

قارن الأرقام بين التجربة 1 و2 في جدول، وهذا جدول النتائج الرئيسي في الرسالة.

**ملاحظات:**
- قياس الطاقة من الرازبيري نفسه **تقريبي**. لو تبي رقم أدق، ركّب جهاز قياس USB-C بين الشاحن والرازبيري.
- كل مرة تفتح الجهاز، أعد الخطوة 1 من القسم د قبل التشغيل.
